1. Purpose

BaseTemplate is a production-ready template designed to eliminate structural regressions and bootstrap new microservice-like monoliths with enterprise requirements already satisfied. By enforcing modularity, security, and caching constraints at compile-time, we maintain quality even as multiple feature slices scale up.

2. Architectural Direction

The solution implements a **logical modular monolith** structure. The frontend targets (Blazor Web & MAUI Mobile) serve as HTTP consumers to the backend controllers API, ensuring zero database connectivity leakage into the UI presentation host.

3. Caching Design & Stampede Prevention

To preserve HybridCache's built-in stampede protection (request coalescing), the cache-aside wrapper in the MediatR pipeline has been refactored. Database-fetching operations must be passed directly into the cache engine factory so concurrent requests for a missing key block and distribute the single database result. 

// Refactored Query caching mapping inside CachingBehavior
var expiration = query.Expiration ?? TimeSpan.FromMinutes(30);

return await _cache.GetOrCreateAsync(
    cacheKey,
    async token => await next(token),
    expiration,
    cancellationToken);

4. Production-First Guidelines

Concern Production Practice Benefit
Database Migrations Run via CI/CD using migration binaries (efbundle) as a deployment step. Never use Database.Migrate() on startup. Prevents database deadlocks and schema locks when scaling out multiple API container instances.
Data Protection API Persist cookies, anti-forgery tokens, and cryptography keys in Azure Blob Storage with Azure Key Vault decryption. Prevents session and anti-forgery invalidation when users hit different scaled container instances.
L1 Cache Drift Enable Redis pub/sub backplane broadcasting within the HybridCache engine setup. Instantly evicts stale L1 memory entries across all load-balanced API servers on write.
PII Logging Configure Serilog destructuring policies to block/mask passwords, tokens, and personal identifying data in target logs. Maintains GDPR and SOC2 compliance without manual audit logs cleansing.
Operational Health Deep active health endpoints that perform query checks against Sql, Redis ping, Key Vault, and Service Bus. Gives accurate indicators to Azure App Gateway / Kubernetes ingress routing tables.

6. Open Decisions

1. Cookie vs Hybrid Authorization in Blazor: Cookies are highly resilient against XSS attacks, but require a reverse proxy/shared domain setup. JWTs scale more easily across cross-origin microservices.

2. Audit Log Staging: Map audits to a local DbContext transaction table, or push them asynchronously to a message broker queue to keep write paths fast.
